# Gestiunea veniturilor și cheltuielilor personale
Proiect realizat în limbajul C, în cadrul facultății de Informatică.

Descriere

Aplicația permite gestionarea veniturilor și cheltuielilor personale pentru o lună de 30 de zile.

Funcționalități

Înregistrarea veniturilor zilnice.

Înregistrarea cheltuielilor pentru alimente, casă și relaxare.

Calcularea veniturilor și cheltuielilor totale.

Calcularea soldului final.

Afișarea statisticilor financiare.

Salvarea detaliilor despre activitățile de relaxare.

Tehnologii utilizate

Limbaj de programare C

GCC Compiler

Visual Studio Code

Concepte de programare utilizate

Vectori și șiruri de caractere

Funcții fără parametri

Structuri decizionale if și switch-case

Bucla do-while
